# بدائل Google لبرامج Microsoft Office


فيما يلي أبرز خدمات Google التي تُعدّ بديلاً مجانيّاً وسحابياً لحزمة Microsoft Office:

### 1. Google Docs (بديل Microsoft Word)

محرر نصوص سحابي يدعم التعاون الفوري والتخزين التلقائي. :br 🔗 <https://docs.google.com/>

### 2. Google Sheets (بديل Microsoft Excel)

جداول بيانات سحابية مع دوال وتحليلات متقدمة ودعم للتعاون الجماعي. :br 🔗 <https://sheets.google.com/>

### 3. Google Slides (بديل Microsoft PowerPoint)

أداة لإنشاء العروض التقديمية مع قوالب جاهزة وخيارات تعاون سهلة. :br 🔗 <https://slides.google.com/>

### 4. Google Forms (بديل Microsoft Forms)

إنشاء استبيانات ونماذج لجمع البيانات بسهولة وتحليلها تلقائياً. :br 🔗 <https://forms.google.com/>

### 5. Google Drawings (بديل Microsoft Visio / الرسوم البيانية البسيطة)

أداة لرسم المخططات والرسوم البيانية البسيطة داخل المتصفح. :br 🔗 <https://drawings.google.com/>

### 6. Google Drive (مساحة تخزين سحابية وبديل OneDrive)

مساحة تخزين ومشاركة الملفات مع إمكانات التكامل مع جميع تطبيقات Google Office. :br 🔗 <https://drive.google.com/>
